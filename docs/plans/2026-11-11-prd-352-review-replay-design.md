## 3. 重放包设计

### 3.1 schema（T2 预埋）

```json
{"schema": "review-replay-pack/v1",
 "input_fingerprint": {"work_id": 42, "work_snapshot_digest": "sha16:…",
   "judgepack_version": "vN", "judgepack_digest": "sha16:…"},
 "decisions": [{"score": "88（原样）", "why": "评分理由（占位）"}],
 "output": {"finding": "入围（占位）", "state": "adopted"}}
```

### 3.2 流程（确定性）

指纹复核（作品/评委包 digest 不符 → REPLAY_INPUT_DRIFT 拒绝）→ 注入同评委包版本重放评分推导（注入式纯函数）→ 结论逐字节比对 → REPLAY_OK / REPLAY_MISMATCH。

## 4. 失败闸门（T3 落地）

| 错误码 | 触发 | 行为 |
|---|---|---|
| REPLAY_INPUT_DRIFT | 作品/评委包指纹不符 | 拒绝重放 |
| REPLAY_MISMATCH | 结论不一致 | 显形+失败证据入账 |
| PACK_INCOMPLETE | 三件套缺一 | 拒绝入账 |
