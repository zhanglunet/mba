## 1. 借鉴对象、许可证与不复用红线

借鉴对象：arcsin1/oh-my-ppt，**Apache-2.0（实测）**。

- **复用**：Apache-2.0 允许复用；但本设计**只借鉴「结构化数据 → 单文件 HTML 幻灯片」的产物形态**。转换器（T2）自研：输出为本仓自研最小内联模板（零框架零构建步骤——纯字符串模板拼接）。

## 3. 转换内核设计

### 3.1 页面结构（T2 预埋）

| 页 | 内容 | 来源 |
|---|---|---|
| 封面 | 评审批次名/日期 | 结论记录头 |
| 作品页 ×N | 每作品一页：作品号 + 逐评委评语（逐字）+ 打分（原值）+ 评委名 | 结论记录逐条 |
| 汇总尾页 | 纯计数（作品数/评委数/零计算排名） | 结论记录计数 |

- **逐页对应规则**（R1）：页序 = 结论记录序；每页的评语条数 = 该作品的评委条数——一对一映射，页内不许合并多条评语；
- 分数呈现格式钉值：原字符串直接输出（如 `8.5/10（占位）`），零格式化。

### 3.2 单文件产物纪律（R3）

```
slides-<批次id>.html
  └─ <style> 全部内联
  └─ 每页 <section>（纯文本 + 内联样式，零 <img> 外链、零 <script>）
```

- 零 `<script>`：幻灯片是静态呈现（翻页用浏览器原生滚动——不造轮子）；
- 零外链：T4 断言产物字符串中零 `http://`/`https://` 资源引用（评语原文里若引用 URL 属**内容**不算资源引用——校验只看标签属性 src/href）。

### 3.3 转换流程（确定性）

1. 读评审结论记录（work_ref 账本/结论记录文件，注入式）；
2. 校验记录完整性（每作品 ≥1 评委条目，缺 → `CONCLUSION_INCOMPLETE` 显形拒绝转换）；
3. 按页结构模板拼接 → 单文件 HTML 写出（原子写）；
4. 回读自检：页面遍历 vs 结论记录逐条比对（R1 断言在转换器内自检，不一致即失败显形）。

## 4. 失败闸门（T3 落地）

| 错误码 | 触发 | 行为 |
|---|---|---|
| `CONCLUSION_INCOMPLETE` | 结论记录缺作品/缺评委条目 | 显形拒绝转换 |
| `SLIDES_PAGE_MISMATCH` | 回读自检页面对应关系断裂 | 失败显形（不产出半成品文件） |
| `EXTERNAL_REF_FOUND` | 模板/内容注入外链资源 | 拒绝（R3 防线在转换器内） |
