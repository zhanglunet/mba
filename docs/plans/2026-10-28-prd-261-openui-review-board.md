## 1. 目标与非目标

**目标**：评审看板不由模型自由写 HTML——**组件库生成系统提示词 → 模型返回组件树 → 网关按同一组件库校验并流式纠错**；非法属性丢弃/纠正；**权限在服务端校验**（前端藏起来的按钮不等于没权限）。产出可信赖的评审看板渲染。

**非目标**：
- 不做自由 HTML 直出路径（本条是对 PRD-081 生成式 UI 的合同化收口）；
- 不改评审判定逻辑——看板只是呈现层，评审结论的产生归既有评审流程与 PRD-151 质量门；
- 不引入前端框架大依赖——组件树校验是纯数据层（JSON），渲染端可用既有站点设施。

## 3. 方案设计

### 3.1 组件库清单（`review-widget-v1`，T1 核心交付）

评审看板允许的组件封闭清单（第一版 8 个，可增须走组件库版本化）：

| 组件 | 用途 | 关键属性（全部封闭枚举/带类型） |
|---|---|---|
| `panel` | 分区容器 | `title`, `level: summary|detail`, `children[]` |
| `verdict-card` | 结论卡 | `verdict: recommend|hold|reject`, `confidence: 0-100`, `rationale_ref` |
| `metric-row` | 指标行 | `label`, `value`, `unit`, `trend: up|down|flat` |
| `table-view` | 数据表 | `columns[]{key,label}`, `rows[][]`, `max_rows` |
| `evidence-link` | 证据引用 | `ref`(findings/材料引用 ID), `label` |
| `checklist` | 检查单 | `items[]{text, state: pass|fail|unknown}` |
| `note` | 文本注 | `body`(纯文本,长度上限), `tone: neutral|warning` |
| `reference-list` | 来源列表 | `refs[]{label, ref}` |

每个组件一份 schema 条目（属性名/类型/枚举/必填/上限），组件库 = 清单 + schema 集合 + 版本号。

### 3.2 提示词生成与组件树解析（T2）

- **提示词由组件库生成**：把 3.1 清单与各组件 schema 编译成系统提示词（"只允许输出以下组件树 JSON…"），模板化生成——组件库变，提示词自动变，不手写漂移；
- 模型返回**组件树 JSON**（不是 HTML）；解析器做第一层校验（JSON 合法、根为 `panel`、深度上限）。

### 3.3 网关校验与流式纠错（T3）

- 校验器逐节点对照 schema：**非法属性丢弃**（记告警）、未知组件替换为 `note(tone: warning)`（内容为"该组件未通过校验"）、必填缺失补占位、值超限截断——全部动作留校验日志（机读）；
- 流式纠错：逐 chunk 校验已到达的子树，发现非法片段立即请求模型重出该子树（纠错请求 ≤2 次，超限整块替换为 warning note）；
- 校验日志随看板产物存档（可回放"哪些东西被丢掉了"）。

### 3.4 服务端权限校验（T4，验收核心）

- 组件树里的每个**动作类属性**（如 `evidence-link` 的打开、`table-view` 的导出）在服务端登记权限点；
- **渲染端隐藏 ≠ 无权**：网关下发组件树时按会话身份过滤动作；用户直接调用动作端点时，服务端再校验权限点（与看板渲染无关的独立校验）；
- 测试场景：构造含用户无权动作的组件树 → 前端被过滤；直接打端点 → 403。两条路都必须拒。

## 4. 安全红线

1. 无自由 HTML 直出：看板唯一渲染源是过校验的组件树（T5 断言渲染产物无 `<script>` 注入面）；
2. **权限在服务端**：动作端点独立校验，与渲染过滤双路（"藏按钮≠没权限"的反向也成立——"显示≠有权"）；
3. 模型输出永不直接入库/渲染——必经网关校验；校验日志留痕；
4. 评审数据引用（evidence-link 的 ref）只指向既有 findings/材料，不内联敏感内容；
5. 示例评审数据全虚构；文档零密钥零内网名。

## 5. T2–T5 任务拆分（按 PRD）

| 任务 | 内容 | 验收标准（PRD 原文口径） |
|---|---|---|
| T2 | 提示词生成 + 组件树解析最小实现 | 样例可解析为组件树 |
| T3 | 网关校验与流式纠错 | 非法属性被丢弃/纠正，有测试 |
| T4 | 服务端权限校验（隐藏控件≠有权） | 越权操作被拒，有测试 |
| T5 | 验收试运行：样例评审看板端到端 | 无自由 HTML 直出；权限服务端生效；无密钥 |

## 6. T5 验收标准

1. 样例评审数据端到端出板：组件树全过 schema 校验，校验日志齐全（丢弃/纠正动作可回放）；
2. 注入非法属性/未知组件样例：被丢弃或替换为 warning note，非法内容零渲染；
3. 越权双路测试：渲染过滤 + 端点 403 都生效；
4. 渲染产物无自由 HTML（无 script/iframe 注入面）；模型输出未过校验不落盘；
5. 全程密钥扫描 0 命中；示例数据全虚构。
