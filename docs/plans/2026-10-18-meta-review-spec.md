## 零、输入数据形状（已核实，以 deepseek v3 报告为准）

- 来源：`published/reports/<brand>/report.md` 的 `## Score Matrix` 章节。
- 实际结构：
  - 矩阵 = **评委 × 维度**。列 = 评委（`display_name_cn`，本例 5 人：杨植麟/王慧文/周鸿祎/傅盛/朱啸虎，
    列数即 panel 人数，**不硬编码**）；行 = 5 个 lens（Origin/起源叙事、Category/品类定义、
    Leverage/杠杆点、Identity/身份系统、Signal/真实信号）。
  - 单元格格式：`分数 + 相对 v2 的移动标记`（如 `9 ↔`、`8→9 ↑1`）。**解析时只取数字部分**，
    `↔`/`↑n`/`→` 是版本 delta 信息，不是本轮打分，直接忽略。
  - 表尾：`Score Total: 208 / 250`（附 v2/v1 对比）、`Score Normalized: 8.32 / 10`。
  - 附带 `Judge Total` 行：每位评委 5 维度总分（如 43/42/44/41/37→38），可做"松紧度"交叉验证。
- 解析规则（T2 实现约束）：
  1. 从 markdown 表格解析出纯数字矩阵 `scores[judge][lens]`；非数字单元格（如 `—`）跳过并记入解析备注。
  2. 报告自带的 `## Dissent Heatmap`（Lens/范围/σ/分歧文字）**不直接采信**：元评审独立重算 σ，
     仅用于交叉对照（一致则互证，不一致则标出差异点）。
- 跨品牌历史：`published/reports/` 下现有 24 个品牌目录（amazon、anthropic、apple、…、zhipu），
  同一评委的多品牌打分真实存在，审计项 3 的跨品牌口径有数据可用。

## 一、审计项固定清单（4 项，每项：输入 → 算法 → 输出）

### 审计项 1：评委间一致性

- **输入**：`scores[judge][lens]` 数字矩阵（N 位评委 × M 个维度）。
- **算法**：
  1. 对每个维度，计算 N 位评委分数的**总体标准差** σ（population std，ddof=0；N=5 时样本/总体口径差异小，
     取总体口径，保证同一输入结果一字不差、可复现）。
  2. 两两评委 Pearson 相关系数矩阵（N×N）：`r(a,b) = cov(a,b) / (σa·σb)`，其中向量为该评委在 M 个维度的打分。
     若某评委所有维度打分完全相同（σa=0），相关系数无定义，该格记为 `—` 并在解析备注中注明原因。
  3. 一致性排序：各维度按 σ **降序**排列。
- **输出**：一致性矩阵（N×N 相关系数表，保留 2 位小数）+ 最低一致维度 Top3（维度名/σ/分数范围）。
- **阈值说明**：本项不设"合格/不合格"硬阈值；σ 只做排序与展示，"分歧是否过大"由人工看 Top3 定
  （措辞纪律见 §四）。

### 审计项 2：离群值

- **输入**：同上。
- **算法**：对每个维度，μ = 该维度 N 位评委均值，σ = 总体标准差；
  若 `|score − μ| > 2σ`，记为一条离群记录。
  - 边界：σ=0（全员同分）时无离群；N<4 时 2σ 统计意义弱，报告标注"样本少，仅供参考"。
- **输出**：离群清单，每条含 评委（display_name_cn）/维度/分数/维度均值/偏离度 `z = (score−μ)/σ`（保留 2 位小数）。

### 审计项 3：系统性偏见（"松紧度"画像）

- **输入**：本报告矩阵 + 历史报告矩阵（同一品牌多版本；跨品牌时取同一评委在多个品牌的打分）。
- **算法**：
  1. 报告内画像：`bias(j) = mean_j − mean_all`，其中 `mean_j` 为该评委 M 个维度均值，
     `mean_all` 为全体评委全部打分的均值。bias>0 偏松（打分偏高），bias<0 偏紧。
     可用 `Judge Total` 行交叉验证（评委总分 − 评委总分均值，符号应一致）。
  2. 跨报告判定：对同一评委，取其在 K 个报告中的 bias 序列；若 **K≥3** 且 bias 符号全部一致
     且 `|mean(bias)| ≥ 0.5`，记为"**疑似**系统性偏见"（注意措辞：疑似，不是定罪）。
  3. 历史样本不足（K<3）时，只出报告内画像，不下"系统性"结论，并在报告中注明样本数。
- **输出**：每位评委的"松紧度"画像（本报告 bias + 跨报告 bias 趋势 + 样本数 K）；
  "疑似系统性偏见"单独成节，措辞纪律见 §四。

### 审计项 4：分歧定位

- **输入**：审计项 1 的 σ 降序表 + 原始矩阵。
- **算法**：
  1. 取 σ Top3 的维度。
  2. 对每个维度，找出分数**最小值**与**最大值**对应的评委（极值有多人并列时全部列出）。
  3. 输出"谁和谁、在哪、差多少"：评委 A（display_name_cn）/ 评委 B / 维度 / 分差 `= max − min`。
  4. 与报告自带的 `## Dissent Heatmap` 分歧文字做对照：描述一致则互证，不一致则在备注中标出差异点。
- **输出**：分歧清单（Top3 维度 × 评委对，附分差与对照结论）。

## 二、报告格式

### 一页审计摘要（120 秒可读，固定结构）

1. **总体一致性评级 A–F**（学 iFixAi 的"120 秒"验收线；评级只反映"分歧程度"，**不等于"打分质量"**）：
   - A：所有维度 σ ≤ 0.5
   - B：最大 σ ≤ 0.8
   - C：最大 σ ≤ 1.2
   - D：最大 σ ≤ 1.8
   - F：任一维度 σ > 1.8
   - （阈值初版：以 deepseek v3 实测 σ 分布 0.00–0.75 为锚定样本；T4 攒够多品牌样本后按真实分布回调，
     回调本身要记 changelog。）
2. **Top3 分歧点**（维度/σ/评委对/分差，一行一条）。
3. **建议复核项**（离群清单 + 疑似系统性偏见；措辞见 §四：只说"建议人工复核"，不说"打分错误"）。

### 附录明细

- 完整 N×N 相关系数矩阵。
- 全部离群记录（含 z 值）。
- 每位评委松紧度画像（含跨报告 bias 趋势与样本数 K）。
- 解析备注（跳过的非数字单元格、σ=0 的维度、相关系数无定义的格子及原因）。

## 三、T2 实现约束

1. **纯计算**：标准库优先（statistics / math 手写 σ 与相关系数公式，见 §六附录）；
   允许用 numpy 但不得新增"必须有 numpy 才能跑"的硬依赖（仓库 CI 自带 pyyaml，见 panel-validation.yml）。
2. **不调 LLM**，不跑真实打分做交叉验证（贵、不稳定；一致性分析只用已有打分）。
3. **确定性**：同一份输入跑 10 次，结果一字不差——无随机、无时间戳、无未排序的字典遍历
   （所有排序显式指定 key，浮点保留 2 位小数）。
4. 输入只读 `## Score Matrix` 解析出的数字矩阵；`↔`/`↑n`/`→` 等版本标记忽略；
   panel 人数/维度数一律从表头/行数推导，不硬编码。

## 四、纪律（不可违反）

1. **只出审计报告，不改分**：不改任何评委的打分逻辑，不改 panel yaml 内容，不做"自动纠偏"
   （发现不一致只报告；纠偏是 T5 之后的事，本 PRD 不做）。
2. **措辞是"分歧点"不是"错误"**：报告定位是"给人工复核的线索"，不下"谁对谁错"的结论；
   "一致性差"不等于"打分错"（评委视角本就该有分歧）。
3. **T4 CI 集成先只报告、不设合并门禁**：PR 改 panel yaml 时自动跑元评审、报告贴 PR 评论；
   阈值与基线跑顺、样本攒够后再讨论是否设门禁。
4. **许可证**：iFixAi（Apache-2.0）只借鉴"独立审计员 + 120 秒可读评级"思路，**不复用其代码**；
   本规范及 T2 实现均为自研。

## 五、T2–T5 接口约定

- T2 输入：`published/reports/<brand>/report.md` 路径；输出：按 §二 的审计报告 Markdown（stdout 或 -o 文件）。
- T3 渲染：在 T2 计算结果上套 §二 的一页摘要格式（A–F 评级 → Top3 → 建议复核项）。
- T4 CI：在 PRD-022 结构测试通过后触发；用仓库已有历史打分做回归基线（新 panel 一致性不比基线差太多，
  "太多"阈值 T4 定，本规范不定）。
- T5 e2e：拿 `published/` 真实品牌打分走通；人工抽查 Top3 分歧点至少 2 个是真问题才算过。

## 六、附录：公式

- 总体标准差：`σ = sqrt(Σ(xi − μ)² / N)`
- Pearson 相关系数：`r(a,b) = Σ((ai − μa)(bi − μb)) / sqrt(Σ(ai − μa)² · Σ(bi − μb)²)`
- 偏离度：`z = (x − μ) / σ`
- 松紧度：`bias(j) = mean_j − mean_all`
