## S2 认领任务

```
任务列表                    认领确认
┌──────────────────┐      ┌──────────────────┐
│ □ 作品A (品牌)   │      │ 认领作品A？       │
```

## S4 打分维度

```
┌─────────────────────────────────────┐
│ 维度          分档        说明       │
├─────────────────────────────────────┤
│ 完整性        1-5         有无缺项   │
│ 一致性        1-5         前后一致   │
│ 创意性        1-5         独特程度   │
│ 可执行性      1-5         能否落地   │
└─────────────────────────────────────┘
注意：全给中间分＝无效评审（T1 步骤清单红线）
```

## S6 三态自查（PRD-177 口径）

```
结论 → confirmed        ✓ 证据充分，直接通过
    → needs_validation  ⚠ 有疑问，标"需复核"
    → rejected          ✗ 明确不可行，写理由
```

## 面板内入口（T4）

评委面板登录后，右上角「帮助」按钮 → 「评委指南」子菜单直达本指南。
指南 URL：`/judge-guide/`（面板 iframe 嵌入或新窗口打开）。
