# PRD-132/T3 评语模板与打分说明（trend #661）

> 红线：模板仅提供结构框架，打分说明不替代评分逻辑

## 评语模板（≥3 套）

### 模板 A：整体评审

```
【品牌一致性】{高/中/低}——{具体观察}
【文案质量】{强/需改进}——{具体建议}
【视觉表现】{优/可优化}——{具体建议}
【总体评价】{一句话结论}
```

### 模板 B：问题发现

```
【问题】{描述问题}
【位置】{具体页面/段落}
【建议】{改进方向}
【严重度】{高/中/低}
```

### 模板 C：通过确认

```
【审核结论】通过
【核验项】{逐项确认：品牌✓ 文案✓ 视觉✓ 合规✓}
【备注】{可选补充}
```

## 打分说明

| 分数 | 含义 | 使用场景 |
|---|---|---|
| 5 | 卓越——超出预期 | 可直接作为标杆 |
| 4 | 优秀——达到高标准 | 少量微调即可 |
| 3 | 合格——基本达标 | 有改进空间但不阻塞 |
| 2 | 需改进——低于标准 | 需要修改后重新提交 |
| 1 | 不合格——严重不足 | 需要重做 |

**注意**：全给中间分（全 3）＝无效评审。
