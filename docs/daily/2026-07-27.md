### 免费社媒线 ②:RSSHub 端到端打通(晚间)

用户在自己 Mac 上跑完 `docs/27` 全部四步并回报。**我做的是公网侧代验**(本沙箱是数据中心 IP,
与 GitHub runner 同一侧 —— 用户本机 curl 通 **≠** 云上通,这一层必须单独证):

- `GET <隧道>/healthz` → **200 `ok`**
- `GET <隧道>/weibo/user/2803301701`(人民日报)→ **200 / ~30KB / 8.6s / 10 条真实条目**,日期当天
- 再过本仓库 `fetch_candidate.parse_feed` → **10 条**、日期全部归一 ISO、链接均带 http 前缀

→ 「家庭 IP 能过微博访客系统」**从机制推断变成实测结论**,`docs/16 §9.9 ③b` 的 Playwright 备选**不必启用**。

**用户踩出来的三条经验(手册里原本没有,已补进 `docs/27`)**:
1. 镜像**必须 `diygod/rsshub:chromium-bundled`**,不是 `latest` —— 新版微博路由走 Playwright 抓
   `m.weibo.cn`,`latest` 没打包浏览器直接报错。
2. macOS 装不上 Docker Desktop(brew 要 sudo 链 `/usr/local/bin`)可用 **OrbStack** 免 sudo 替代。
3. `cloudflared` 默认走 **QUIC(UDP 7844)**,很多网络阻断 → 加 `--protocol http2` 走 TCP 443 才通。
   **连不上先试这个,别怀疑 RSSHub。**

**我拒绝做的一件事:不把这个 URL 提交进 `reports-meta.yaml`。** 两个理由都写进 `docs/27 §F`:
- 临时 `trycloudflare` 隧道**重启即变、进程停即断** → 填进去等于每日流水线请求死链、哨兵天天告警;
- 它**默认无鉴权且公网可达** —— 我这台无关的数据中心机器能直接拉到数据,就是证据。
  任何扫到它的人都能用用户的 IP 与带宽去请求微博,**风控算在他头上**。
  → 正式接线的前置条件:**命名隧道 + `ACCESS_KEY`**。

教训一句话:**"我这边能访问"和"云上能访问"是两个命题**;而**验证成功不等于可以上线**——
这次验证用的载体本身带着两个上线级缺陷。

### 正式接线准备:命名隧道手册 + 两个真 bug(深夜)

用户问"命名隧道怎么建、本机还要配什么",写了 `docs/29`(20 分钟走完:上锁 → 建隧道 →
免 sudo LaunchAgent → 公网侧三段验收 → 密钥进 secrets)。**顺带发现三件必须先修的事**:

1. **公开仓库不能存明文密钥** —— 本仓库 `visibility: public`,而 RSSHub 的 key 必须跟在 URL 上。
   把 `?key=<真串>` 写进 `reports-meta.yaml` = **公开发布密钥**。
   → meta 只存 `${RSSHUB_KEY}` 占位符,真值走 Actions secrets,由 `expand_secrets()`
   在 runner 内存展开;**变量缺失时跳过该源并明确喊「环境变量未设置」**,而不是拿空 key 去请求
   ——空 key 会 403,那会**把配置错误伪装成路由故障**,排错追错方向。
   日志与候选 md 打印的永远是模板串。新增 `check_consistency` 第 16 格拦明文(做了 red-green)。

2. **自备 RSS 被知乎 100% 静默挤掉(真 bug,差一点就发给用户了)** —— 端到端拿真 feed 试跑时
   发现:`parse_feed` 明明拿到 10 条,候选里**一条都没有**,而且**哨兵不响**(源确实抓到了,
   只是没进候选)。查下来是名额桶:自备 RSS 与知乎共用「社区 ≤1/4」且**排在知乎后面**,
   meituan 上知乎 53 条,`soc[:3]` 全被占满。
   → 改成桶内 `own` 优先(**显式配置 > 顺带召回**),总名额不变;名额逻辑抽成纯函数
   `_apply_quota()` 补 6 组**真跑**断言。
   **要点:如果不做端到端真跑,用户会在装完隧道后拿到 0 条微博,而且看不出哪里坏了。**

3. **候选 md 的 `source_type` 写死 `media`** —— JSON 侧一直按召回路径给对了,给人看的那份却
   硬编码 `media`。人工照抄 = 把官方公告和微博条目全标成媒体。改为按召回路径填。

教训:**"门禁绿 + 单测绿 + 源码看着对" 三件齐了,端到端仍可能是 0 条**。
昨天的教训是「门禁绿 ≠ 产物对」,今天这条更狠:**没有报错的 0 条,比报错更难发现**。
